# Voco

A minimalist, Voice-First Event RSVP Engine that converts standard RSVP lists into personalized, AI-generated voice reminders to increase event attendance.

## Tech Stack

- React
- Vite
- Node.js
- pnpm
- Llama-3

## Folder Structure

- `/voco`: Frontend application built with React and Vite. Provides a minimalist light-mode dashboard for CSV roster uploads, campaign tracking, and audio preview playback.
- `/api`: Backend service built with Node.js and Express. Handles CSV ingestion, MongoDB Atlas persistence, Llama-3 script generation, and ElevenLabs voice synthesis.

## Use Cases

- Technical community events seeking to improve registrant turnout.
- Field operations teams coordinating high-touch logistics to reduce RSVP drop-off.

## Hacktoberfest Integration

- **Render**: Hosts the Node.js API and open-weight model integration.
- **MongoDB Atlas**: Serves as the primary database for events and attendee statuses.
- **ElevenLabs**: Synthesizes the text generated by the open-weight model into human-sounding audio.
- **Sentry**: Traces backend API performance and monitors AI inference latency.
